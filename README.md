# Underside
## 公開URL
ブラウザ上でプレイできます。 URL：https://unityroom.com/games/underdside
## 概要
「Underside」はどちらのスライムが勝利をするのかを予想をするゲームです。
計３回賭けフェーズがありまして、最終的なコインの所持数でエンドが分岐するように作成しています。
## Githubについて
こちらは前作の反省を踏まえて、参照しやすいように一通りの進捗を終わらせたらブランチを切る方式にしました。
revertの機能があるのは理解をしているが、gitの操作が慣れていないためこのような方式をとらせていただきました。
## 実装した主な機能
- 自動で動くステートメント
- UniTaskを活用したアニメーションの処理
- 賭け金システム
  ソースコードに生成AIを活用しました
## 工夫した点
UIの設計について、ユーザー側が快適にゲームをプレイできるように見やすさを工夫をいたしました。例えば今回ではuniTaskを活用して演出を盛り上げるようなアニメーションを実装いたしました。
## 反省点
個人的にはもっと単純な設計にすればよかったと感じております。オッズ機能は私が入れてみたかった機能でしたが今回では1v1形式であったのであまり意味をなさなかったです。
ですのでゲーム性を面白くするために必要な機能と不必要な機能の見極めが重要だと思いました。
